# Opera Dragonfly

The developer tools client for the Presto engine.

## Directories

`src`: the client. The only directory the build reads.

`tools`: `df2`, which builds it, and the retired tooling that came before.

`tests`, `test-scripts`, `manual-test-suite`: test pages.

`doc`, `classes`: service interfaces generated by `hob`. `doc` was part of `src/lib` until 2010, when the client began building its service interfaces at run time from the host's own protocol description instead; both have been reference material since.

## Building

    ./build.sh

Produces `build/`, with one client document and script bundle for every maintained localization and one shared stylesheet. Nothing has to be installed first; `df2` lives in `tools/df2` and needs Python 3.9 or later.

## Working on the client

Build, then point the browser at the result: open [opera:config#DeveloperTools|DeveloperToolsURL](opera:config#DeveloperTools|DeveloperToolsURL) and set it to the `client-en.xml` in your `build/`.

The developer tools window grants its document control of the browser, so it follows only `file:` and `opera:` URLs. Serving the client over http needs `Developer Tools Allow Any Scheme` set as well.

Leaving the preference empty loads the client the browser shipped with, which is how to get back to a known state.

The historical workflow used `dragonkeeper`, a proxy that served `src/` unbuilt so that no build step was needed. It is Python 2 and unmaintained since 2014, so it does not run here; building is the supported path.

## Translations

`src/ui-strings` holds them and is now where they are edited. Originally it was generated output, and the authoritative strings lived in Opera's translation infrastructure as .po files that were never public; that is gone.

`tools/po2js.py` converts a .po file to the JavaScript form, and the client can load one at run time from its general settings.

The default build includes every maintained translation in the same output directory. Each localized script begins with the complete English strings as fallbacks and then applies the available translated strings.
